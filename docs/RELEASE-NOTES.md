原生 macOS / Windows 托盘截图工具。支持区域截图、手动滚动自动拼接、基础标注及 PNG 导出。

macOS 使用固定项目证书，尚未 Developer ID 签名或 Apple 公证。首次安装可能被 Gatekeeper 阻止；请阅读 README 中的安装说明，不要关闭系统安全保护。

具体变更见下方自动生成的版本记录。真实桌面验收步骤见 docs/ACCEPTANCE.md。滚动截图不适用于所有窗口，固定栏、悬浮元素、动画和动态消息可能导致暂停。

Windows 安装包自带 .NET 运行时，支持 x64 / ARM64，尚未 Authenticode 签名。请核对官方来源，不要关闭 SmartScreen 或防病毒。Windows 的交互支持边界与人工验收见 docs/WINDOWS.md。
