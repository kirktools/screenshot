# 隐私说明

## 截图内容

Screenshot 在本机采集、拼接、编辑和编码图片，不上传截图，没有注册、遥测或第三方分析服务。只有用户唤起截图后才开始相应采集，不在后台持续录制。

普通截图为支持冻结背景、拖动边框和向外扩选，会临时读取显示器快照；在像素预算内可能包含所有连接的显示器，而不只包含最初选区。超过预算时会缩减保留范围。只有最终选区及用户标注被导出。

长截图采集用户选择的单屏滚动区域，不采集音频。完成或取消后停止屏幕流。截图过程不需要麦克风、辅助功能或输入监控权限。

## 保留与导出

编辑中原图及撤销历史留在内存。关闭普通截图编辑会释放整屏扩选快照和历史；为支持“打开上次预览”，当前选区图片及标注会保留到被下一次预览替换或应用退出。取消编辑同样不表示立即安全擦除当前选区内存。

日常使用不会自动把原始截图写到缓存或开发日志。用户主动保存时写入所选 PNG 文件；复制时将渲染后的 PNG 放入系统剪贴板。打码为导出位图中的实心覆盖，不附带可撤销图层或原图。

通用剪贴板、剪贴板历史工具、系统备份及用户选定的同步目录由系统或第三方软件管理，不属于本应用的数据控制范围。

## 权限与联网

屏幕录制权限由 macOS 管理，应用不能自动绕过或放宽。重建、更换签名或安装路径后可能需要用户重新授权。

只有用户主动检查更新、下载确认的更新或打开 Release 页面时才访问 GitHub。GitHub 可接收正常请求的 IP、时间及固定 User-Agent 等网络信息；截图、标注及窗口内容不会随请求发送，当前版本号在本地比较。

公开 Release 使用 HTTPS；私有仓库开发验收可复用本机已经登录的 GitHub CLI，应用不保存令牌或自动登录。更新缓存和备份保存的是安装包、应用和更新结果，不是截图。

## 开发与测试

合成测试不读取真实桌面。显式执行 `--capture-smoke-test` 等真实采集诊断时，需要已有权限，并会按测试说明把结果写入指定目录或系统临时目录；不要对敏感桌面运行这些诊断，完成后自行清理输出。

个人验收、审计和权限排障过程保存在被 Git 忽略的 `.local/` 或 `.build/`，不作为公开项目资料提交。
