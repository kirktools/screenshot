# 人工验收

记录系统版本、芯片、显示器尺寸/缩放和应用版本；用非敏感内容。自动测试不能替代真实桌面权限和交互验证。每项记录“通过 / 失败 / 未测试”，不要把未测试写成通过。

## 权限与启动

- 从固定路径启动 .app，确认菜单栏图标、首次设置和默认快捷键；关闭设置仍驻留。
- 在从未授权的系统账户申请屏幕录制；首次拒绝后再次点击截图，不应崩溃，能打开系统设置。
- 授权并重启后截图成功；撤销、重启后再次截图有明确引导。不要通过重置整个机器的权限数据库做验收。
- 尝试被占用快捷键，应提示冲突且旧绑定仍可用；改为 ⌃⌥S，重启确认持久化。应用不请求辅助功能/麦克风权限。

## 普通截图与多屏

- 单屏框选，Esc 放弃；截图尺寸为区域点尺寸 × backingScale；检查中文字和像素边缘。
- 两块屏幕分别选择：主屏左/右/上/下排列、负坐标、Retina 与 1× 混合缩放。
- 跨屏框选检查内容相对位置、方向、接缝、尺寸与透明空隙；最高缩放归一化可能放大低 DPI 部分。
- 采集中插拔/重排显示器，应用应中止并提示重新框选。

## 长截图：三类目标应用分别执行

| 场景 | 选区与操作 | 预期 |
| --- | --- | --- |
| 浏览器静态长文章 | 排除地址栏、sticky 导航、滚动条；鼠标滚轮和触控板分别连续滚动 5 屏，不逐次停顿；包含惯性减速 | 无缺行、重行、反转、接缝错位 |
| 微信聊天 | 非敏感测试聊天，排除会话标题、输入框、悬浮日期、滚动条；向下滚动 | 每条消息恰好出现一次，焦点仍在微信 |
| Codex 对话 | 停止生成，排除顶部栏、底部输入框、固定按钮；向下滚动 | 中文、代码块和引用顺序正确，目标窗口仍接收滚动 |

每类检查：边框持续可见且鼠标/滚轮穿透，已捕获内容预览常驻并实时跟随末尾；控件和选择边框不进入结果；把捕获面板移到选区上方也应排除其图像；点击面板后再将鼠标放回内容区，目标应用仍接收滚轮。回车 / ✓ 应直接将完整 PNG 放入剪贴板并关闭，不出现编辑器；铅笔图标才进入编辑；下载图标复制并打开 PNG 保存框，取消保存仍保留剪贴板内容。主界面只保留预览和图标，悬停有说明；更多菜单能访问撤销、重试、放大、跟随和尺寸。正常滚动、短暂接续、完成处理不显示提示。明确出错时显示不抢焦点、鼠标穿透的独立悬浮提示；提示出现、更新和恢复消失时，预览面板及工具栏的屏幕位置、尺寸都不应变化。Esc 取消（包括目标应用全屏模式）。会话结束后回车/Esc 恢复目标应用常规行为。

异常操作：一次跳两屏、反向滚动、停在重复列表、改变页面缩放、调整窗口大小、加入固定栏、播放动画/视频、让新消息到达。预期短暂失配先恢复、持续失配停止追加并显示等待接续，不擅自接入错误片段；细小变化可能漏检，必须放大检查结果。回滚到上一段附近应自动恢复，无需点击重试；撤销后段数和高度减少，再回滚也应自动恢复；无法继续时完成已有片段或取消。始终不稳的应用应明确记录为当前不支持。

## 编辑与导出

- 箭头/矩形顺向和反向拖动；文字含中文、英文和换行（当前文本输入为单行）；裁剪四个方向。
- 撤销/重做标注和裁剪；执行新编辑后重做历史应清空。
- 在敏感文字区域打码，保存 PNG，用 Preview 放大确认黑色实心覆盖而不是独立图层；裁剪和打码后再复制比较 PNG。
- 复制粘贴到 Preview/聊天输入框；取消保存不报错；不可写路径有错误提示；重新读取 PNG，验证尺寸、方向、透明度和颜色。
- 长图滚动到最底部编辑/保存；重复开始与取消 20 次，观察 Activity Monitor，无明显会话资源累积。

## 连续采集专项回归

- 连续滚动时无需每段停稳，中文正文、代码行、头像和消息应无缺行重行；放大查看拼接处。
- 快速跳两屏应保留已确认内容并提示，不能假装完整。失配后直接完成，需明确确认仅导出已有部分。
- 惯性回弹后恢复向下可自动接续；持续向上应停止追加并提示等待接续。重试与撤销后立刻完成不得悄悄跳过未验证内容。
- 点击完成时立即停止滚动，检查最后可见的新增行已接入；Esc 取消后没有残留面板、会话键或录制流。
- 捕获时改变屏幕缩放、拔插显示器，应中断接续并提示重新框选。
- `--scroll-session-self-test` 以合成帧验证会话（无需桌面权限）；`--capture-smoke-test` 还验证真实 SCStream 首帧与三次启停（需已有录屏权限）。两者不能代替上述真实应用验收。

## 原位标注与浮动工具栏

- 普通截图保留在框选位置；工具栏靠近选区，屏幕边缘时保持可见。负坐标、跨屏和 Retina 选区分别检查。
- 直接画箭头、矩形、打码和裁剪；点击文字工具后直接在图片上输入中文，回车确认文字，Esc 只取消当前文字；再次回车复制并结束。
- 点 ✓ 完成复制后遮罩与工具栏均消失；Esc/× 取消不修改剪贴板。保存对话框应在遮罩上方，取消保存仍保留编辑。
- 普通截图工具栏切换长截图会关闭冻结画面并重新激活目标应用；边框保留，滚轮不被边框或状态面板抢走。
- 长图结束后沿用浮动标注界面，可滚动到末尾编辑；不显示独立的带标题大编辑窗口。
- 状态面板的放大/缩小及“跟随末尾”开关均不改变采集区域，控件不得进入最终图片。近全屏选区还应检查贴边控件是否挡住所需内容。

## 样式与预览回归

- 普通截图中滚轮/触控板上下左右操作均不移动图片或产生回弹；长图仍可正常滚动。
- 圆形、矩形、箭头分别测试不同颜色及粗细，旧标注不随新画笔变化；撤销重做、复制及 PNG 均保留各自样式。打码始终实心黑色。
- 一进入滚动捕获就能看到已捕获的第一屏，继续滚动预览跟随新增末尾，整张长图不会越缩越小。
- “放大预览”后文字更易读，缩小后保持布局；关闭“跟随末尾”后可滚动回看，再次勾选后恢复末尾跟随。
