# 人工验收

记录系统版本、芯片、显示器尺寸/缩放和应用版本；用非敏感内容。自动测试不能替代真实桌面权限和交互验证。每项记录“通过 / 失败 / 未测试”，不要把未测试写成通过。

## 权限与启动

- 从固定路径启动 .app，确认菜单栏图标、首次设置和默认快捷键；关闭设置仍驻留。
- 在从未授权的系统账户申请屏幕录制；首次拒绝后再次点击截图，不应崩溃，能打开系统设置。
- 授权并重启后截图成功；撤销、重启后再次截图有明确引导。不要通过重置整个机器的权限数据库做验收。
- 尝试被占用快捷键，应提示冲突且旧绑定仍可用；改为 ⌃⌥S，重启确认持久化。应用不请求辅助功能/麦克风权限。

## 普通截图与多屏

- 单屏框选，Esc 放弃；截图尺寸为区域点尺寸 × backingScale；检查中文字和像素边缘。
- 两块屏幕分别选择：主屏左/右/上/下排列、负坐标、Retina 与 1× 混合缩放。
- 跨屏框选检查内容相对位置、方向、接缝、尺寸与透明空隙；最高缩放归一化可能放大低 DPI 部分。
- 采集中插拔/重排显示器，应用应中止并提示重新框选。

## 长截图：三类目标应用分别执行

| 场景 | 选区与操作 | 预期 |
| --- | --- | --- |
| 浏览器静态长文章 | 排除地址栏、sticky 导航、滚动条；每次滚 1/3 屏停 0.6 秒，连续 5 段 | 无缺行、重行、反转、接缝错位 |
| 微信聊天 | 非敏感测试聊天，排除会话标题、输入框、悬浮日期、滚动条；向下滚动 | 每条消息恰好出现一次，焦点仍在微信 |
| Codex 对话 | 停止生成，排除顶部栏、底部输入框、固定按钮；向下滚动 | 中文、代码块和引用顺序正确，目标窗口仍接收滚动 |

每类检查：缩略图实时更新；控件和选择边框不进入结果；把捕获面板移到选区上方也应排除其图像；点击面板后再将鼠标放回内容区，目标应用仍接收滚轮。回车完成、Esc 取消（包括目标应用全屏模式）。会话结束后回车/Esc 恢复目标应用常规行为。

异常操作：一次跳两屏、反向滚动、停在重复列表、改变页面缩放、调整窗口大小、加入固定栏、播放动画/视频、让新消息到达。预期暂停提示，不擅自接入错误片段；细小变化可能漏检，必须放大检查结果。回滚到上一段附近点击重试；撤销后段数和高度减少，再回滚重试；无法继续时完成已有片段或取消。始终不稳的应用应明确记录为当前不支持。

## 编辑与导出

- 箭头/矩形顺向和反向拖动；文字含中文、英文和换行（当前文本输入为单行）；裁剪四个方向。
- 撤销/重做标注和裁剪；执行新编辑后重做历史应清空。
- 在敏感文字区域打码，保存 PNG，用 Preview 放大确认黑色实心覆盖而不是独立图层；裁剪和打码后再复制比较 PNG。
- 复制粘贴到 Preview/聊天输入框；取消保存不报错；不可写路径有错误提示；重新读取 PNG，验证尺寸、方向、透明度和颜色。
- 长图滚动到最底部编辑/保存；重复开始与取消 20 次，观察 Activity Monitor，无明显会话资源累积。
