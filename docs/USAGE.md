# 使用与开发指南

截图操作、权限排查、构建选项与支持范围。快速了解项目请看 [README](../README.md)。

## 系统与开发要求

运行：macOS **14 Sonoma 或更新版本**，Apple Silicon 或 Intel。选择 14 是因为采用 SCScreenshotManager 的单帧 API，避免旧截图 API 和额外流管理。参见 [Apple ScreenCaptureKit 文档](https://developer.apple.com/documentation/screencapturekit/scscreenshotmanager)。

构建：Swift **6.0+**、对应 macOS SDK、Xcode Command Line Tools 即可，无第三方包。`swift test` 的 XCTest 运行需要完整 Xcode；仅装 Command Line Tools 时用 `scripts/test-core.sh` 运行同一批算法用例。Swift 语言模式为 5，兼容当前 Swift 6 工具链。最低系统版本是编译目标，不代表已在所有支持系统实测。

```bash
xcode-select --install # 尚未安装开发工具时
scripts/test-core.sh  # 不依赖 XCTest，可用于只有 Command Line Tools 的环境
make dev            # 更新并启动固定安装路径的测试版
```

单独运行 `scripts/build-app.sh` 可生成 `dist/Screenshot.app` 及与 `VERSION` 对应的 ZIP/DMG 安装包。默认本机构建架构；`UNIVERSAL=1 scripts/build-app.sh` 构建 arm64/x86_64 双架构，`CONFIGURATION=debug` 可改为调试构建。用 Xcode 打开 `Package.swift` 也可浏览调试，但日常运行建议使用固定位置的 `.app`，以稳定权限身份。

受限执行环境若无法写默认 Swift/Clang 缓存，可把 `CLANG_MODULE_CACHE_PATH` 与 `SWIFTPM_MODULECACHE_OVERRIDE` 指向工作区 `.build/cache/clang`，并为 SwiftPM 指定 `--cache-path`。不应为应用运行关闭系统保护。

## 本地验收 PR

切换代码后只需运行：

```sh
make dev
```

命令构建当前代码（包括未提交修改），校验签名完整性和语言资源，然后退出旧截图进程、备份并更新固定的 `/Applications/Screenshot.app`，最后启动。只构建本机架构，跳过 ZIP/DMG 打包；不切换分支、不推送、不发版本。需要 Swift 6+、Xcode Command Line Tools 和 Python 3。

例如通过编号验收 PR，无需创建或占用已有分支（把 123 改为目标 PR 编号）：

```sh
pr=123
git fetch origin "pull/$pr/head"
git switch --detach FETCH_HEAD
make dev
```

这是临时检出该 PR 提交用于测试。切换前请提交或暂存自己的修改；测试结束可 `git switch master` 返回。无需为测试注册 `gh` 账号，使用仓库现有 Git 访问方式即可。

应用设置底部会显示源码分支/提交、是否有本地修改，以及实际安装路径。请从此固定安装路径启动，避免同时运行 `dist`、下载目录或 `~/Applications` 的副本；先完成或取消当前截图再更新，卡住的截图进程会被结束。

旧应用保存在当前仓库 `.build/dev-backups/` 的 ZIP 中，更新失败会恢复原目录。恢复某份旧版时先退出截图应用，再解压该 ZIP 并放回 `/Applications`。脚本本身的更新、校验失败和回滚可用 `make dev-test` 验证，测试仅使用临时假应用。

`make dev` 不修改 Gatekeeper、录屏开关或其他隐私权限，也不会自动使用 sudo。本机源码构建不经过浏览器下载隔离流程，但 ad-hoc 签名变化仍可能使已有录屏授权失效；这时只为固定路径这份应用授权并重新启动。不能保证每次构建都免重新授权。

## 安装与权限

建议把应用安装到 `/Applications` 后首次启动，并保持唯一的日常安装副本。当前构建仅 **ad-hoc 签名**，不是 Developer ID 签名，也没有 Apple 公证。网络下载的包可能被 Gatekeeper 拦截；确认来源后可按 macOS 提示在“系统设置 → 隐私与安全性”中使用“仍要打开”（若系统允许）。不要关闭 Gatekeeper、SIP 或全局放宽安全策略；本地从源码构建是另一条路径。

启动只显示菜单栏图标；通过菜单「设置」在截图前申请“屏幕与系统音频录制 / 屏幕录制”（不同系统名称稍异）。只读屏幕像素，不申请麦克风、辅助功能或输入监控权限。全局快捷键采用 Carbon 热键注册，滚动由你在原应用内完成。

首次拒绝后，使用设置里的「打开系统录屏设置」按钮打开系统设置并勾选 Screenshot。授权、撤销或重新授权后可能需要退出再启动。若仍失败，确认设置中的应用与正在运行的包路径相同；重建、更换签名或路径可能让系统重新识别应用。不要把每次权限弹窗都当作拼接错误。

## 重启后找不到应用或快捷键无响应

手动启动和双击重新打开 `.app` 都仅驻留菜单栏；设置通过菜单或应用激活时 ⌘, 打开。当前未配置随 macOS 登录自动启动，重启电脑后需要手动打开应用。

注册快捷键前会读取 macOS 已启用的系统快捷键。系统可能自定义了 `⌘⇧7`，这时不能仅根据 `RegisterEventHotKey` 返回成功就认为可用：应用会自动尝试备用长截图键 `⌃⌥7`，显示原因并保存实际绑定；区域截图的备用键为 `⌃⌥2`。如果备用键也不可用，窗口会显示提示，可通过按钮截图或另设组合键。请以状态窗口中显示的绑定为准。

若得到一条很扁的 Touch Bar 图片，是触发了系统截屏动作，而不是本应用的长截图界面。先打开应用，点击“区域截图”或“滚动长截图”按钮，区分键盘冲突和录屏权限问题。返回设置窗口时会重新检查权限状态；授权后按系统提示退出并重新打开同一路径的应用。开发版重新构建后，ad-hoc 签名变化可能需要再次授权。

## 使用

1. 菜单栏选择“区域截图”或按快捷键，移动鼠标会预选前方普通窗口，单击或回车确认；也可直接拖动框选自定义区域，Esc 放弃。窗口预选只识别窗口外框，不自动识别网页子区域、聊天正文或控件；长图仍建议手动框选正文以避开固定栏。候选列表在每次唤起时获取，框选期间不要移动目标窗口；下次唤起会重新读取。
2. 普通截图在原选区显示冻结画面与浮动工具栏，不再跳到独立编辑窗口。默认预选窗口单击确认后，也可直接拖动选区边框或八个角点/中点调整范围，无需额外确认；调整使用首次冻结的屏幕画面，已有标注保持屏幕位置，连续一次拖动算一步撤销，裁剪后仍可调整。编辑画布内部继续用于标注。框选、滚动与编辑使用同一套常驻高对比描边；四角显示对应方向的斜向双箭头，边缘显示水平或垂直调整光标。滚动采集中区域固定，需要改范围时先取消并重新框选。可直接画箭头/矩形/圆形、裁剪、打码；工具栏可选择 7 种颜色和 3 档线宽，每条标注独立保留样式；文字工具点击图片直接输入，回车确认文字，Esc 放弃本次文字输入。工具栏的长截图按钮可在当前区域重新采集滚动内容（不保留普通截图上的标注）。
3. 长截图只框选一个滚动容器的正文；避开顶部栏、底部输入框、滚动条、悬浮按钮。原应用恢复焦点后，鼠标留在内容区，可连续向下滚动，无需每次停顿；避免拖动滚动条跳页、快速跨越多屏。
4. 滚动期间选区边框始终保留，鼠标和滚轮穿透。浮动面板优先放在选区外，只保留已拼接预览和图标工具栏，默认跟随末尾。鼠标悬停图标可看说明；“更多”（…）中提供撤销、重试、放大、跟随末尾及尺寸/段数。预览保持横向比例，可滚动查看。明确失配后，悬浮提示显示“等待接续（仍在识别）”。此时，向上回到预览末尾附近，有可靠重叠后会自动接续，无需点重试。“撤销上一段”删除最后片段，回到保留片段末尾附近也会自动恢复。尺寸变化、权限/采集错误和资源上限仍停止采集，需要按提示重试或重新框选。
5. 长截图按回车 / ✓ 直接复制到剪贴板并结束，不默认进入编辑。需要标注时点击铅笔图标，结束采集后进入编辑；下载图标复制并打开 PNG 保存对话框，取消保存仍可从剪贴板粘贴。Esc / × 丢弃会话。末尾尚未可靠匹配时仍需再次确认才仅导出已确认部分。普通截图画面固定，不接收滚轮也不弹性回弹；显式进入长图编辑后可滚动检查和标注。编辑时点 ✓ 或按回车复制并退出；`⌘C` 仅复制并保留界面，保存按钮 / `⌘S` 保存 PNG，Esc / × 取消。文字尚在输入时先回车确认文字，再回车完成截图。裁剪和打码都实际改变导出像素；仍可在关闭编辑前撤销。

## 支持范围与限制

适合静态、向下垂直滚动、无固定覆盖的正文区域。当前不支持从初始画面向上扩展长图；短暂向上回弹可恢复，持续反向会暂停。重点人工验收对象为浏览器网页、微信聊天记录、Codex 对话；**尚未宣称这些应用全部通过实测**。

不支持水平/双向连续拼接、自动驱动滚动、窗口缩放/移动中的捕获、混合多个滚动容器或跨屏长截图。固定标题、悬浮元素、视频、闪烁光标、动画、动态消息、懒加载重排和高度重复内容可能导致暂停；某些细小变化仍可能漏检。请缩小区域、停止动态内容、避开固定栏；必要时使用普通截图。内容被其他应用遮挡时会截到遮挡物。

被处理的相邻画面之间至少需约 22% 重叠；采集目标为 30 fps，实际速度受屏幕、系统与识别耗时影响，过快跳跃仍可能无法接续。上限为长图高 30000 像素、3200 万像素、保留条带与匹配帧合计 256 MB；普通截图最多 4000 万像素。长图和编辑历史会额外占内存。没有 OCR、自动去固定栏、智能窗口识别或登录启动。选区几乎占满屏幕、四周空间不足时，状态面板/工具栏会贴近屏幕边缘，可能覆盖部分视野；本应用界面会从采集图像中排除。输出为 sRGB PNG；多数细节提示尚未翻译成英文。

## 测试与贡献

```bash
scripts/test-core.sh
swift test  # 完整 Xcode 环境 / CI
swift run Screenshot --self-test
# 可选：验证真实剪贴板，随后恢复已有数据
SCREENSHOT_TEST_CLIPBOARD=1 swift run Screenshot --self-test
```

算法测试覆盖精确重叠、重复帧、重复纹理、重叠不足、噪声、Retina 高度、像素尺寸变化、同视口缩放、反向滚动、固定栏及动态内容拒绝。`--self-test` 不读取桌面，验证真实 CGImage 拼接方向、编辑渲染、裁剪撤销/重做、PNG 编解码、打码像素与文件写入；默认测试 PNG 写入系统临时目录。真实交互见[验收清单](ACCEPTANCE.md)。

欢迎 Issue 和 PR。提交时说明 macOS、芯片、屏幕缩放、复现步骤与期望结果；测试图片请用合成内容，勿上传私人聊天截图。新增算法行为应附可复现测试；UI 修改附截图和交互验证结果。架构演进见 [ARCHITECTURE.md](ARCHITECTURE.md)，自动测试与发布见 [RELEASING.md](RELEASING.md)。

### 普通截图的改选区范围

首次截图保留屏幕快照，编辑中不会重拍动态内容。多显示器按最高快照比例归一化输出；边缘按像素对齐，屏幕空隙保持透明。快照总量限制为 4000 万原生像素，超限时只保留初始选区所在显示器；仍超限则只保留初始选区，工具栏尺寸提示的悬停说明会告知范围受限。改选区后单张输出也限制为 4000 万像素。长图编辑不提供扩选边框。

显示器排列或缩放在编辑中发生变化时，改选区停止；请完成现有截图或取消重新框选。撤销最多 30 步，同时受约 256 MB 历史图像估算上限约束。关闭编辑会释放整屏快照和调整历史，保留上次图片预览；重新打开上次预览可标注，但不能扩展到原图以外。


## 应用内更新

菜单栏或设置中选择「检查更新…」，发现更高正式版后，点击「更新并重启」。仅检查 `kirktools/screenshot` 的非预览 Release，不自动检查、不上传截图，也不安装 PR 构建或降级版本。

应用须位于 `/Applications/Screenshot.app`，且当前用户可写该目录。更新先验证文件大小、SHA-256、ZIP 路径、包标识、版本、当前架构及代码签名，再备份和替换；助手就绪后旧应用才退出。安装期间不开始新截图；下载时可关闭窗口取消，重新打开可重试。无需 `sudo`。

公开仓库直接使用 HTTPS；目前仓库私有时，可复用本机已经安装并登录的 `gh`（需有仓库读取权限）。应用不会读取、保存令牌或自动登录。没有可用权限、正式版或校验文件时会说明原因，不尝试其他来源。

旧版 ZIP 保留在 `~/Library/Caches/com.kirktools.screenshot/Updates/Backups/`，结果记录为同级 `last-result.txt`。替换失败自动恢复旧版；恢复也失败时会保留旧目录并报告位置，可退出应用后从备份解压恢复到 Applications。备份由用户自行清理。

更新不解决未公证应用的系统限制：保留下载隔离标记，macOS 仍可能要求核验后「仍要打开」；ad-hoc 签名改变也可能需要重建录屏授权。后续完成 Developer ID 签名和公证后才能改善这一体验，勿关闭系统安全保护。


## 菜单栏与名称

启动或再次打开应用只保留菜单栏图标，不自动弹设置。点击菜单栏的「设置」，或在应用激活时按 **⌘,** 打开设置；关闭后继续驻留。未授权时按截图快捷键只显示简短提示，点击提示中的「打开设置」才进入设置，不自动申请权限。

应用展示名、窗口及安装包内的应用统一为 **Screenshot**，固定安装路径为 `/Applications/Screenshot.app`。Bundle ID 仍是 `com.kirktools.screenshot`，快捷键偏好保留；组织名和仓库仍为 kirktools/screenshot。新 ZIP/DMG 使用 `Screenshot-版本-macOS`；更新器仍可读取旧的 `Kirk-Screenshot-版本-macOS.zip` 资源。

本地 `make dev` 检测到仅有旧的 `/Applications/Kirk Screenshot.app` 时，验证应用身份、备份后迁移到新路径；失败恢复旧名称，不同时保留两份。若新旧两份均存在，或新路径属于其他应用，会停止并说明原因，不覆盖其他软件。手动拖入 DMG 时也应先退出并备份旧版，避免留下两份。路径和 ad-hoc 签名变化后，macOS 仍可能要求重新录屏授权；本命令不重置权限。
