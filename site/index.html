把操作留给肌肉记忆

三步，拿到截图。

  1. 01

    按快捷键

    ⌘ ⇧ 2 普通截图
    ⌘ ⇧ 7 滚动长截图
    Windows：Ctrl+Shift+2 / 7

  2. 02

    框选内容

    拖动框选；macOS 也可单击预选窗口。长图框选单一正文区域，再向下滚动。

  3. 03

    回车复制

    按 ↩ 完成，按 Esc 取消。长图需要编辑时点铅笔，需要保存时点下载。

安装时提示来源或开发者无法验证？

macOS 发布尚未完成 Apple Developer ID 签名及公证，Windows 尚未做 Authenticode 签名。确认下载来自官方 GitHub Release 后，按系统提示核验来源。不要关闭 Gatekeeper 或 SIP。macOS 首次截图需授予屏幕录制权限；Windows 请完整解压到可写目录，并保留系统安全保护。安装与权限说明 ↗

所有页面都可以截长图吗？

适合静态、向下滚动的正文。固定栏、悬浮元素、动画、动态消息和重复纹理可能影响拼接；请尽量避开。暂不支持向上扩展或跨屏长图，也不保证适配所有应用。

截图会上传吗？

应用内采集、拼接、编辑和导出都在本机完成。只有主动检查更新、下载更新或打开 Release 页面时才访问 GitHub。隐私说明 ↗

快捷键和系统冲突了怎么办？

可在设置里重新配置。默认长截图组合可能与部分 Mac 的 Touch Bar 截图冲突；请以设置中实际注册成功的组合为准。
