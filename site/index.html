把操作留给肌肉记忆

一个入口，三步完成。

  1. 01

    按快捷键

    ⌘ ⇧ 2 唤起截图。
    长图和 GIF，都能从框选后进入。

  2. 02

    框选内容

    拖动框选，或单击预选窗口，再拉边框微调。工具栏选择标注、长图、GIF 或贴图。

  3. 03

    回车复制

    截图按 ↩ 复制、Esc 取消；GIF 手动开始、停止后预览保存。长图默认直接复制。

先了解这些

简单，也有边界。

安装时提示无法验证开发者？

当前发布尚未完成 Apple Developer ID 签名及公证。确认下载来自官方 GitHub Release 后，按系统提示核验来源。不要关闭 Gatekeeper 或 SIP。首次截图需授予屏幕录制权限。安装与权限说明 ↗

所有页面都可以截长图吗？

适合静态、垂直滚动的正文，可向上下两端扩展。支持稳定的边缘固定栏和靠底部的局部悬浮栏。中央遮挡、动画、动态消息、固定栏中途变高和重复纹理仍可能影响拼接。长图没有固定高度门槛，但受内存和像素预算约束。暂不支持水平拼接或跨屏长图，也不保证适配所有应用。

GIF 可以录多久？

最长 60 秒，最高 10 fps，最长边 1280 像素，不录制声音或光标。达到时长、帧数或缓冲预算后自动结束并预览；GIF 色彩有限，不替代视频录屏。

截图会上传吗？

应用内采集、拼接、编辑和导出都在本机完成。只有主动检查更新、下载更新或打开 Release 页面时才访问 GitHub。隐私说明 ↗

快捷键和系统冲突了怎么办？

可在设置里重新配置，也可以关闭“长截图独立快捷键”，只保留普通截图一组，从工具栏选择长图或 GIF。默认长截图组合可能与 Touch Bar 截图冲突；以设置中注册成功的组合为准。
